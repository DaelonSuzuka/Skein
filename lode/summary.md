# Skein Summary

Skein is a Godot 4 **editor plugin** for authoring interactive conversations. It combines a visual node-graph editor with an **expanded Yarn text format** so writers can edit dialog outside Godot or in a plain text editor. Skein is designed to scale from one-line NPC barks to full visual-novel-length branching trees. Dialog can directly reference and mutate game state via GDScript blocks (`{ }` silent, `{{ }}` printing). The in-game `DialogBox` is intended as a customizable template rather than a final UI. Character registration exists but character management is incomplete. A quest system coevolved with the dialog runtime is a long-term goal. The plugin registers an autoload singleton (`Skein`) via `plugin.gd` and must cleanly handle enable/disable cycles without leaking resources.
