# Skein Summary

Skein is a Godot 4 editor plugin that combines a Yarn-like dialog DSL with a visual node-graph editor for managing interactive conversations. It provides an inline syntax for character portraits, conditional choices, code execution, and BBCode text formatting, all editable within the Godot editor via a custom main screen (SkeinEditor). Conversations are stored as `.yarn` or `.json` files under `res://conversations/` and characters as `.tscn` scenes under `res://characters/`.
