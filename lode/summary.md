# Skein Summary

Skein is a Godot 4 **editor plugin** for authoring interactive conversations. It rejects the Visual Programming Block approach (à la Dialogic) in favor of **text-first authoring** — writers edit `.yarn` files in any text editor and the graph is a convenience layer, not a prison. Dialog can directly reference and mutate game state via GDScript blocks (`{ }` silent, `{{ }}` printing). The in-game `DialogBox` is a bring-your-own-scene template — you own the UI, Skein doesn't manage it. Characters are `.tscn` scenes in a directory, not entries in a proprietary registry. Skein is designed to scale from one-line NPC barks to full visual-novel-length branching trees. Character registration exists but the character standard hasn't graduated from the Isotope prototype. A quest system coevolved with dialog is a long-term goal. The plugin registers an autoload singleton (`Skein`) via `plugin.gd` and must cleanly handle enable/disable cycles without leaking resources.
